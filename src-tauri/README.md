# src-tauri/ — Rust desktop shell

> **Status: implemented.** Tauri 2 shell with tray, frameless window, close-to-tray, Python sidecar handshake and the bundled portable Ollama runtime. The Windows build runs in CI and in the release workflow; it needs a first green run on Windows.

Layout:

```
src-tauri/
├── Cargo.toml
├── Cargo.lock
├── tauri.conf.json          # window, CSP, bundle config, NSIS language selector
├── tauri.release.conf.json  # adds the PyInstaller backend sidecar as a resource
├── capabilities/            # minimal per-window permission sets
├── icons/                   # generated by scripts/generate_icons.py
└── src/main.rs              # app setup, tray, sidecar handshake, window behaviour
```

Non-negotiable rules:

- The Python backend is started by the shell and terminated on exit; no orphan processes.
- The shell passes the port and the per-run session token to the UI; tokens are never written to disk.
- Tauri permissions are minimal and explicit; new capabilities need justification in review.
- The CSP allows only the local UI bundle and the local WebSocket backend; no remote origins.
- Closing the window hides it to the tray; quitting happens from the tray menu.
